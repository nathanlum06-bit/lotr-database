# Lord of the Rings Database

## CMSC 4323 - Database Systems Final Project

A relational database based on the Lord of the Rings universe.

## Project Requirements

- 12+ database tables
- ORM implementation
- CRUD operations
- Multiple JOIN query
- VIEW
- STORED PROCEDURE
- CHECK or UNIQUE constraint
- INDEX
- Populated database
